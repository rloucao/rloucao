## Featured work

### hoppin: end-to-end encrypted, offline-first messenger
<!-- Add the repository or website link here -->
[![Website](https://hoppin.chat)

`Swift` `Python` `Next.js` `CryptoKit`

- End-to-end encryption protocol built on CryptoKit, with an anonymous outer layer so mesh relays can't see who is talking to whom
- Peer-to-peer delivery over Bonjour/Wi-Fi, plus multi-hop Bluetooth mesh routing when there is no internet
- Python relay and certificate authority; the relay stores only sealed envelopes and deletes them on delivery
- Trust-on-first-use key pinning, safety numbers, QR verification and key-change warnings
- 300+ Swift and Python tests running against shared protocol fixtures
